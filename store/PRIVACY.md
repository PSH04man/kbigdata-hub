# K-BigData Hub 개인정보처리방침

시행일: 2026-11-25

K-BigData Hub(이하 "확장프로그램")는 사용자의 개인정보를 수집하거나 개발자 서버로 보내지 않습니다.

## 1. 다루는 정보
| 정보 | 용도 | 저장 위치 |
|---|---|---|
| GitHub 토큰 | 사용자가 지정한 GitHub 저장소에 코드 파일을 올리기 위해 | 사용자 브라우저(chrome.storage.local) |
| 저장소·브랜치·폴더 설정, 테마 | 설정 유지 | 사용자 브라우저(chrome.storage.local) |
| 사용자가 작성한 답안 코드, 문제 번호·제목·주소, 제출 일자, (설정을 켠 경우) 350제의 문제 문장·입출력 예제 | GitHub에 올리기 위해 (코드·SQL 파일과 README.md) | 저장하지 않음(올릴 때만 전송) |

## 2. 정보를 보내는 곳
정보처리 실기에서는 SQL 작성 문제만 올립니다. 문제 지문과 해설은 올리지 않습니다. 기초 코딩 350제는 "문제도 함께 올리기"를 켠 경우(기본값) 문제 문장·난이도·분류·입출력 예제를 README.md에 함께 올립니다. 해설과 정답 코드는 올리지 않습니다.

- **GitHub (api.github.com)**: 사용자가 "맞혔어요"를 누르고 올리기를 허락했을 때, 답안 코드와 README.md(문제 번호·제목·문제 주소·제출 일자), 커밋 메시지를 사용자의 저장소로 보냅니다. 같은 문제를 다시 올릴 때 파일 이름을 맞추려고, 사용자의 저장소에서 해당 문제 폴더의 파일 목록을 읽습니다. 사용자가 파일 이름을 바꿔 올리면 그 폴더의 예전 풀이 파일을 지우는 변경을 같은 커밋에 담습니다.

그 밖의 어떤 서버로도 정보를 보내지 않으며, 광고·분석·추적 도구를 쓰지 않습니다.

## 3. 삭제
확장프로그램을 삭제하면 브라우저에 저장된 토큰·키·설정이 모두 지워집니다. 이미 GitHub에 올린 파일은 사용자의 저장소에 남으므로, 지우려면 GitHub에서 직접 지워 주세요.
